# 실제 풀이 기록과 보정 준비

2026-10-04. 자동으로 난이도를 변경하는 기능이 아니다. 실제 기록이 쌓이기 전에는 시간·학년 보정이 완료됐다고 표현하지 않는다.

## 이용 흐름

- 완료한 퀴즈만 최근 50회까지 이 브라우저에 보관한다. 이름·계정·연령을 받지 않고 서버로 자동 전송하지 않는다.
- 결과 아래의 ‘풀이 기록 내려받기’는 JSON 파일을 제공한다. ‘저장된 풀이 기록 삭제’는 풀이 기록을 지운다. 문제 반복 방지용 최근 문항 ID는 유지한다.
- 저장 차단·용량 부족이면 현재 페이지의 메모리에서 계속 플레이하고 내려받을 수 있다. 새로고침 뒤 보존되지는 않는다. 중간 종료한 회차는 기록하지 않는다.

## 기록과 요약

회차 ID·완료 시각·문제은행 내용 버전·결과 학년과 근거, 각 문항의 ID·내용 버전·학년·영역·지문·질문·표시 보기·정답·선택 답·결과·제한시간·응답시간·관측시간·화면 이탈 여부를 포함한다.

- 보기 섞기 전후의 문항 버전은 같지만, 지문·보기·정답·학년·영역·제한시간 변경은 다른 버전으로 집계한다. 내용 버전은 보안 용도가 아닌 편집 비교용 fingerprint다.
- 응답시간은 엔진이 제한시간까지 기록한 값이다. 관측시간은 실제 응답 이벤트까지의 경과시간이며 브라우저 중단 시 제한시간을 넘을 수 있다.
- 문제 도중 탭/앱을 벗어난 회차의 해당 문항은 interrupted로 보존하고 요약의 정답률·시간 초과율·시간 중앙값에서 제외한다.
- 정답률과 시간 초과율의 분모는 화면 이탈이 없는 전체 문항 응답이다. 넘기기도 분모에 포함하되 별도 개수로 표시한다.
- 정답 시간 중앙값은 화면 이탈이 없고 1초 이상인 정답만 사용한다. 1초 미만 정답의 정오답 기록 자체는 유지한다.
- 동일 문항·동일 버전별 응답 수·정오답·넘기기·시간 초과·이탈·보기별 선택 횟수·정답 시간 중앙값을 함께 내보낸다.
- 화면 이탈 없는 응답 5개 미만은 needsMoreSamples로 표시한다. 5개는 검증된 통계 기준이 아니고 탐색용 표시다. 한 기기의 반복 플레이를 서로 다른 참가자로 취급하지 않는다.

## 보정 순서

1. 수집한 기록에서 버전·이탈·넘기기를 구분하고 표본 규모를 확인한다.
2. 정답자의 시간도 제한시간에 가까우면 읽기 부담을 우선 점검한다. 제한시간을 자동 연장하지 않는다.
3. 특정 오답에 몰리면 실제 혼동인지 문항의 모호성인지 다시 검수한다.
4. 학년 간 난이도는 서로 다른 학습 수준의 이용자 기록으로 비교한다. 개인정보나 재학 학년을 현재 기능에서 수집하지 않으므로 이 기록만으로 학년 정확도를 확정할 수 없다.
5. 보정 전후 버전을 분리해 비교하고, 부족한 유형을 먼저 추가한다.

## 검증

기록 왕복·정답 텍스트·20/30초 제한시간·보기 섞기 버전 보존·편집 버전 분리·이탈 제외·시간 초과와 넘기기 분리·1초 미만 시간 제외·손상 저장소·50회 상한을 단위 테스트한다. 브라우저 smoke에 저장·다운로드·삭제 검사를 추가했다. 단위 테스트 성공과 실제 브라우저 실행 여부는 구분한다.

이번 실행에서 엔진·빌드·기록 테스트 25개가 통과했다. 브라우저 smoke는 Chromium 실행 파일이 없어 시작하지 못했으므로 저장·내려받기·삭제 UI의 실제 브라우저 검증은 남아 있다.

## 판정 정책 버전

새 기록에는 문제은행의 bankVersion과 별도로 estimationVersion을 저장한다. 정책 버전은 엔진의 ESTIMATION_VERSION에서 가져온다. 버전이 없는 기존 기록은 그대로 읽고 내려받으며, 그 정책은 미상이다. 현재 버전을 과거 기록에 채워 넣거나 기존 결과를 자동 재판정하지 않는다. 선택적 필드 추가이므로 export schemaVersion과 로컬 저장 키는 1을 유지한다. 문항 정답률 summary는 콘텐츠 버전별 집계를 유지하며 학년 결과를 비교할 때는 기록의 estimationVersion을 함께 확인한다.
