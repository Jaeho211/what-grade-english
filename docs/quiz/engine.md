# 적응형 엔진 프로토타입

## 현재 범위

갱신: 2026-10-04. 실제 문제은행은 초6~고3 7레벨 각 72문항, 총 504문항/91슬롯이다. `startQuiz`의 기본 범위는 1~7이며 콘텐츠 부족 시 오류를 낸다. 중1~중3 부분 범위 검증도 유지한다.

## 출제 정책

- 중2에서 시작해 정답이면 한 단계 상승, 오답/넘기기/시간 초과면 한 단계 하락한다.
- 처음 네 문항은 네 영역을 하나씩 탐색한다.
- 8~10번째 문항은 매 응답 뒤 확인 학년을 다시 계산한다. 지금까지 맞힌 최고 수준 이하에서 남은 문항을 모두 맞히면 확정 조건을 충족할 수 있는 가장 높은 학년을 선택하고, 그 학년의 부족한 정답 영역을 우선 확인한다. 상위 학년 확정이 불가능해지면 하위 학년의 직접 근거를 보충한다. 어느 학년도 확정 가능하지 않으면 현재 잠정 추정 학년을 확인한다.
- 동일 ID 재출제는 금지한다. 현재 레벨 안에서 미출제 skill, 직전과 다른 영역, 미출제 family를 우선한다. 후보 부족 시 유형 반복은 허용하지만 레벨을 임의로 바꾸지는 않는다.
- 최근 ID 목록은 최신순이며, 초반 영역 탐색과 마지막 판정 영역 확인을 먼저 보장한 뒤, 해당 후보 안에서 최근 미출제 문항만 선택한다. 모두 최근 문항이면 가장 오래된 것을 선택한다. skill/family 다양성은 그다음에 비교한다. UI는 최근 400개 ID를 로컬 저장하며 저장이 차단돼도 플레이를 허용한다.
- 현재 실제 은행은 속도 가속을 모두 꺼 두었다. 보정 후 명시적으로 활성화한 문항에서만 1초 이상·문항 기준시간 이내 정답을 두 단계 상승에 사용할 수 있다.

## 최종 학년 근거

높은 레벨부터 다음 조건을 모두 만족하는 학년을 확정한다.

- 해당 학년 직접 정답 최소 2개.
- 해당 학년 및 상위 학년 정답 합계 최소 3개.
- 정답 영역 최소 3개이며 독해 또는 글의 흐름을 포함한다.
- 해당 학년 직접 응답의 정답률 최소 75%. 시간 초과와 넘기기도 직접 응답 분모에 포함한다.

상위 정답은 정답 개수와 영역을 보완하지만 해당 학년 직접 정답률을 높이지 않는다. 상위 오답은 하위 학년을 감점하지 않는다. 확정 학년이 없으면 기존 부분 근거 정책을 유지한다. 해당 학년 응답과 상위 정답을 합산한 정답 두 개 이상·서로 다른 정답 영역 두 개 이상·정답률 75% 이상인 가장 높은 학년을 provisional로 반환한다. 부분 근거는 직접 두 정답을 확인한 확정과 구분한다. 한 문항 또는 한 영역 정답만으로 잠정 상위 학년을 부여하지 않으며, 확정 학년이 있으면 잠정 상위 학년보다 우선한다.

부분 근거도 부족하면 지원 범위의 최저 학년을 provisional로 반환한다. basis는 confirmed/partial/floor로 표시 근거를 구분한다. 하한 표시는 숙달 확인이 아니다. 시간 초과·넘기기는 별도 기록하지만 현재 정답률 계산에서는 해당 레벨의 미정답으로 유지한다. 시간 초과 가중치는 실측 전 임의로 완화하지 않는다.

이는 재미용 정책이며 통계적으로 보정된 능력 추정 모델은 아니다. 추후 플레이에서 반복되는 과대/과소 판정이 확인되면 정책을 조정한다.

## API 및 타이머

`startQuiz(bank, options)`는 첫 pending 문항을 돌려준다. `submitAnswer(bank, state, answer, elapsedMs, options)`는 기존 state를 변경하지 않고 다음 상태를 돌려준다. answer는 0~3 또는 skip/timeout이다. 짧은 어휘는 15,000ms, 문맥 어휘·문장 이해는 30,000ms, 짧은 글 읽기·글의 흐름은 40,000ms 이상 응답을 정답을 골라도 timeout으로 처리한다. UI와 엔진은 timeLimitMs로 같은 기준을 사용한다. 열 번째 응답 이후 pending은 null이고 result가 존재한다.

UI는 시간 측정에 단조 증가하는 시계를 사용하고, 동일 상태에 대한 중복 클릭을 차단해야 한다. 보기 섞기는 `shuffleChoices`가 정답 인덱스도 함께 바꾼다. 섞인 pending 문항을 상태에 보관해야 표시 보기와 채점 인덱스가 일치한다.

## 검증 결과

- 전체 504문항/91슬롯 구조 검증 통과. 문항 난이도 정확성을 보장하지 않는다.
- 중학교 부분 범위 및 실제 7레벨 은행의 1,024개 정오답 경로 × 8개 시드 검사.
- 전체 18개 엔진/빌드/배포 설정 테스트 통과(2026-10-04).
- 모든 정답, 초반 실수 후 회복, 영역 편중, 하한 처리, 타이머, 넘기기, 보기 섞기 및 최근 기록 검사.
- 배포 사이트에서 시작 → 첫 문제 → 정답·해설 표시를 브라우저로 확인했다. 전체 브라우저 smoke suite 통과를 의미하지 않는다.
- 별도 정적 TypeScript 검사와 실제 사용자 기반 난이도 보정은 아직 없다.

## 후속 검토

두 영역 부분 근거 정책을 적용했다. 중간 수준의 잠정 판정, 한 문제·한 영역 방지, 정확도 경계, 확정 결과 우선, 상위 실패 보존을 검사했다. 실제 이용자의 학년 정확도와 시간 초과 가중치는 추가 보정이 필요하다. 요구사항과 우선순위는 [제품 기준](../product-plan.md)을 따른다.

### 재도전 검증 (2026-10-04)

정답·오답·넘기기 각각 8회 연속 재도전에서 필수 영역 후보에 새 문항이 남아 있으면 최근 ID를 재출제하지 않음, 후보 소진 시 가장 오래된 ID를 선택함, 첫 4문항 영역 균형과 회차 내 중복 금지를 검사한다. 최근 기록은 최대 400개이며 현재 504문항 전체를 기억할 수 있다. 브라우저 smoke는 이 환경에 Chromium 실행 파일이 없어 실행하지 못했다. 추가 168문항의 난이도·시간은 실제 사용자 실측 전 임시값이다.

## 짧은 어휘와 풀이 리듬 (2026-10-04)

생각할 시간이 필요한 문항의 지문 길이는 유지하며 문맥 어휘·문장 이해는 30초, 독해·글의 흐름은 40초로 조정한다. 새 짧은 어휘는 15초다. 초6~고3 각 4문항(28문항)을 추가해 총 364문항/91슬롯이다. 단어의 기본 뜻을 짧은 한국어 보기로 확인하고 문맥이 의미를 직접 설명하는 추론 문제와 구분한다. 학년은 앱 내부 난이도 기준이며 공식 단어별 학년 배정을 의미하지 않는다. 실제 학년별 정답률 검증은 아직 수행하지 않았다.

기본 문제은행에서는 첫 네 문제의 네 영역 균형을 유지하면서 어휘 차례에 짧은 어휘를 하나 출제하고, 6번째 문제에 두 번째 짧은 어휘를 출제한다. 이후 어휘가 선택되면 기존 문맥 어휘를 사용한다. 총 10문제와 여러 영역의 정답을 요구하는 학년 판정 기준은 유지한다. 짧은 어휘를 추가했다고 전체 어휘를 네 문제로 고정하지 않는다. 속도 가속은 기존 문제은행처럼 실측 보정 전 비활성화 상태를 유지한다.

### 재도전용 어휘 확장 (2026-10-04)

짧은 어휘를 학년별 4개에서 24개로 늘렸다(140개 추가, 총 168개). 기존 문맥 어휘 12개와 합쳐 학년별 어휘는 36개이며 전체 문제은행은 504개다. 회차당 짧은 어휘 2개 정책은 유지한다. 학년별 24개는 같은 학년에서 짧은 어휘만 보면 12회분의 규모이며, 학년 이동·영역별 후보·최근 기록 만료에 따라 반복 시점은 달라질 수 있다. 최근 400개 ID 회피 및 후보 소진 시 오래된 문항 우선 정책을 유지한다. 모든 단어는 서로 다른 짧은 어휘이며 정답과 오답은 같은 품사 또는 같은 의미 범주로 구성한다. 실제 학년 난이도는 플레이 데이터로 보정한다.

## 경계 학년 확인 개선 (2026-10-04)

총 10문항, 처음 네 영역 탐색, 6번째 짧은 어휘, 기존 시간 제한을 유지한다. 8~10번째 학년 선택은 남은 문항으로 직접 정답 수·전체 정답 수·영역 수·직접 정답률 조건을 충족할 수 있는지 계산한다. 예를 들어 고3에서 1정답·2실패 후 두 문항이 남으면 모두 맞혀도 3/5이므로 고3 확인을 중단한다. 반면 1정답·1실패 후 세 문항이 남으면 회복 가능하므로 고3 확인을 계속할 수 있다. 확인 단계에서도 한 영역 정답만으로 확정하지 않는다.

## 판정 이유와 상위 부분 근거 표시 (2026-10-04)

낮은 확정 학년을 높은 잠정 학년보다 우선하는 정책을 유지한다. 세 영역의 낮은 학년 직접 정답과 두 영역의 높은 학년 정답이 함께 있으면 낮은 학년을 표시하되, 결과 설명에 높은 학년의 부분 근거를 별도로 표시한다. 상위 부분 근거는 기존 잠정 조건(정답 2개·2영역·관련 정답률 75%)으로 계산하며 확정 학년으로 승격하지 않는다. 부분 근거가 없더라도 상위 정답이 있으면 일부 상위 문제를 맞혔다는 사실만 설명한다.

결과 화면은 판정 학년 이상에서 실제 출제된 학년별 정답 수, 판정 학년의 직접 정답 수, 판정에 사용된 영역 및 전체 오답·시간 초과·넘김 수를 표시한다. 하한 결과는 숙달 근거를 확인한 것으로 표현하지 않는다. 화면 설명은 resultDetails가 실제 history에서 집계하고 estimate 결과를 변경하지 않는다.

엔진 정책 버전은 ESTIMATION_VERSION으로 관리한다. 이번에 기존 직접 근거 정책에 `2026-10-04.direct-evidence-v1`을 부여하며, 출제·판정·시간 정책이 바뀌면 버전도 갱신해야 한다. 설명만 바뀌는 경우는 같은 버전을 유지한다. 버전 표시 이전 기록은 소급 분류하지 않는다.
