# 적응형 엔진 프로토타입

## 현재 범위

갱신: 2026-10-04. 실제 문제은행은 초6~고3 7레벨 각 48문항, 총 336문항/84슬롯이다. `startQuiz`의 기본 범위는 1~7이며 콘텐츠 부족 시 오류를 낸다. 중1~중3 부분 범위 검증도 유지한다.

## 출제 정책

- 중2에서 시작해 정답이면 한 단계 상승, 오답/넘기기/시간 초과면 한 단계 하락한다.
- 처음 네 문항은 네 영역을 하나씩 탐색한다.
- 8~10번째 문항은 가장 높은 정답 레벨에서 정답 근거가 부족한 영역을 우선 확인한다. 이 레벨이 최종 확정 학년이라는 뜻은 아니다.
- 동일 ID 재출제는 금지한다. 현재 레벨 안에서 미출제 skill, 직전과 다른 영역, 미출제 family를 우선한다. 후보 부족 시 유형 반복은 허용하지만 레벨을 임의로 바꾸지는 않는다.
- 최근 ID 목록은 최신순이며, 초반 영역 탐색과 마지막 판정 영역 확인을 먼저 보장한 뒤, 해당 후보 안에서 최근 미출제 문항만 선택한다. 모두 최근 문항이면 가장 오래된 것을 선택한다. skill/family 다양성은 그다음에 비교한다. UI는 최근 400개 ID를 로컬 저장하며 저장이 차단돼도 플레이를 허용한다.
- 현재 실제 은행은 속도 가속을 모두 꺼 두었다. 보정 후 명시적으로 활성화한 문항에서만 1초 이상·문항 기준시간 이내 정답을 두 단계 상승에 사용할 수 있다.

## 최종 학년 근거

높은 레벨부터 확인해 정답 세 개 이상, 서로 다른 정답 영역 세 개 이상, 정답률 75% 이상이면 확정한다. 특정 레벨의 분모는 그 레벨 응답 및 상위 정답이다. 상위 오답은 하위 지식의 부정 근거로 사용하지 않는다. 확정 학년이 없으면 같은 근거 집계 방식으로 정답 두 개 이상·서로 다른 정답 영역 두 개 이상·정답률 75% 이상인 가장 높은 수준을 provisional로 반환한다. 한 문항 또는 한 영역의 정답만으로 잠정 상위 학년을 부여하지 않는다. 상위 정답은 하위 근거로 인정하므로 특정 학년의 실패 후 그 아래 수준의 잠정 근거가 남을 수 있다. 확정 결과가 있으면 잠정 상위 결과보다 우선한다.

부분 근거도 부족하면 지원 범위의 최저 학년을 provisional로 반환한다. basis는 confirmed/partial/floor로 표시 근거를 구분한다. 하한 표시는 숙달 확인이 아니다. 시간 초과·넘기기는 별도 기록하지만 현재 정답률 계산에서는 해당 레벨의 미정답으로 유지한다. 시간 초과 가중치는 실측 전 임의로 완화하지 않는다.

이는 재미용 정책이며 통계적으로 보정된 능력 추정 모델은 아니다. 추후 플레이에서 반복되는 과대/과소 판정이 확인되면 정책을 조정한다.

## API 및 타이머

`startQuiz(bank, options)`는 첫 pending 문항을 돌려준다. `submitAnswer(bank, state, answer, elapsedMs, options)`는 기존 state를 변경하지 않고 다음 상태를 돌려준다. answer는 0~3 또는 skip/timeout이다. 문맥 어휘·문장 이해는 20,000ms, 짧은 글 읽기·글의 흐름은 30,000ms 이상 응답을 정답을 골라도 timeout으로 처리한다. UI와 엔진은 timeLimitMs로 같은 기준을 사용한다. 열 번째 응답 이후 pending은 null이고 result가 존재한다.

UI는 시간 측정에 단조 증가하는 시계를 사용하고, 동일 상태에 대한 중복 클릭을 차단해야 한다. 보기 섞기는 `shuffleChoices`가 정답 인덱스도 함께 바꾼다. 섞인 pending 문항을 상태에 보관해야 표시 보기와 채점 인덱스가 일치한다.

## 검증 결과

- 전체 336문항/84슬롯 구조 검증 통과. 문항 난이도 정확성을 보장하지 않는다.
- 중학교 부분 범위 및 실제 7레벨 은행의 1,024개 정오답 경로 × 8개 시드 검사.
- 전체 18개 엔진/빌드/배포 설정 테스트 통과(2026-10-04).
- 모든 정답, 초반 실수 후 회복, 영역 편중, 하한 처리, 타이머, 넘기기, 보기 섞기 및 최근 기록 검사.
- 배포 사이트에서 시작 → 첫 문제 → 정답·해설 표시를 브라우저로 확인했다. 전체 브라우저 smoke suite 통과를 의미하지 않는다.
- 별도 정적 TypeScript 검사와 실제 사용자 기반 난이도 보정은 아직 없다.

## 후속 검토

두 영역 부분 근거 정책을 적용했다. 중간 수준의 잠정 판정, 한 문제·한 영역 방지, 정확도 경계, 확정 결과 우선, 상위 실패 보존을 검사했다. 실제 이용자의 학년 정확도와 시간 초과 가중치는 추가 보정이 필요하다. 요구사항과 우선순위는 [제품 기준](../product-plan.md)을 따른다.

### 재도전 검증 (2026-10-04)

정답·오답·넘기기 각각 8회 연속 재도전에서 필수 영역 후보에 새 문항이 남아 있으면 최근 ID를 재출제하지 않음, 후보 소진 시 가장 오래된 ID를 선택함, 첫 4문항 영역 균형과 회차 내 중복 금지를 검사한다. 최근 기록은 최대 400개이며 현재 336문항 전체를 기억할 수 있다. 브라우저 smoke는 이 환경에 Chromium 실행 파일이 없어 실행하지 못했다. 추가 168문항의 난이도·시간은 실제 사용자 실측 전 임시값이다.
