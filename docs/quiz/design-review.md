# 구현 전 설계 검토

2026-10-03

## 유지할 방향

초6~고3 7레벨, 네 영역, 10문제·20초, 검수 문항, 탐색 난이도와 결과 분리를 유지한다. 84슬롯은 커버리지 목표이며 난이도 보장은 아니다.

## 개선 사항

- 초반 네 영역 탐색 → 중반 경계 탐색 → 후반 부족한 영역에서 추정 학년 재확인. 3영역 정답을 요구하려면 출제기가 확인 기회를 보장해야 한다.
- 정답 3개·정답 영역 3개·정답률 75%는 초기 정책이며 실측 보정이 필요하다. 상위 실패를 하위 학년 분모에 모두 넣지 않는다. 속도는 탐색에만 사용한다.
- 결과는 단일 학년으로 유지하되 confirmed/provisional을 내부 구분한다. 모든 오답의 초6 표시는 숙달 확인이 아니라 결과 범위의 하한이다.
- domain은 출제 분류이며 통계적으로 독립적인 능력이 아니다. 동일 지문을 여러 영역 증거로 재사용하지 않는다.
- slotId는 교육과정 슬롯, skill은 학년을 넘어 공유하는 능력, familyId는 유사 문제 형태다. 학년별 skill 이름만 다르게 붙여 동일 유형을 반복하지 않는다.
- 20초 분량은 지문+질문+네 보기 전체로 검수한다. 질문은 한국어를 기본으로 하고 불필요한 희귀 어휘와 배경지식 의존을 줄인다.
- 공식 어휘 수는 학습 분량 기준이며 단어 빈도 순위가 아니다. 900/1200을 자동 단어 필터로 사용하지 않는다.
- 임의 단어 치환 대신 검수 문항과 보기 섞기부터 시작한다. 최근 문항 기록으로 재도전 반복을 줄이되 후보 부족 시 오래된 기록부터 완화한다.
- 첫 구현은 L3 12슬롯×2문항으로 검증한다. L1~L7 콘텐츠 없이 전체 학년 판정 앱을 공개하지 않는다.
- 1024개 정오답 경로는 종료·경계 검사다. 타임아웃/넘기기/속도/랜덤 시드/능력별 모의 응답도 확인한다. 실제 플레이 없이 학년 정확도를 주장하지 않는다.

## 검증 기준

전부 정답의 고3 도달·확정 가능성, 초반 실수 후 회복, 한 영역 편중 방지, 모든 오답 하한 처리, 부족한 문제은행 명시, 정답 위치 분포, 모바일 보기와 타이머 가독성을 확인한다.
