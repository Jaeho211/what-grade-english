# 7레벨 앱 연결

7레벨 × (기존 12슬롯 × 4문항 + 짧은 어휘 24문항) = 504문항을 정적 앱에 연결했다. TypeScript 엔진을 그대로 사용하며 Node 24의 타입 제거 기능으로 빌드한다. UI는 DOM/CSS이며 빌드 시 합친 JSON을 가져온다.

시작/문제/해설/결과 화면, 15~40초 타이머, 넘기기, 다시 풀기, 문제별 내 답·정답 검토를 제공한다. 지문은 일반 문장 형태로 표시하고 해설 공간은 응답 후 생성한다. 보기 섞기는 pending의 정답 인덱스도 함께 변경한다.

응답 후에는 해설의 끝과 다음 문제 버튼이 보이도록 자동 스크롤한다. 움직임 줄이기 설정에서는 즉시 이동한다. 다음 문항에서는 화면 상단으로 즉시 복귀한 뒤 타이머를 시작하여 이전 해설의 스크롤 위치가 남지 않게 한다.

첫 응답 후 상태를 동기적으로 잠가 중복 클릭을 방지한다. 타이머는 performance.now와 Date.now 경과 시간 중 큰 값을 사용해 백그라운드 복귀 시에도 만료를 확인한다. 해설 읽는 시간은 다음 문항에 포함하지 않는다. 최근 400개 ID만 로컬 저장하며 저장 실패 시에도 플레이는 가능하다.

공유는 Web Share → 클립보드 → 수동 복사 순서다. 개인 기록 동적 OG 이미지는 아직 없다.

Cloudflare Workers: 저장소의 wrangler.jsonc로 npm run build를 실행한 후 dist 전체를 배포한다. 배포 명령은 npx wrangler deploy, Node 24 이상. public만 배포하면 실행용 JS와 문제은행이 빠진다. 모든 자산 경로는 상대적이다.

구조·엔진·빌드 테스트는 학년 난이도 정확성을 보장하지 않는다. 실제 학생/성인 플레이로 유형별 15~40초 읽기 부담, 보기 길이, 고1~고3 난이도 차이와 오답 매력도를 보정해야 한다. 공식 기본 어휘 목록 대조도 필요하다. expectedMs는 임시값이며 속도 가속은 아직 꺼져 있다.

2026-10-04 배포 후 실제 브라우저에서 시작 화면 → 첫 문항 → 정답·해설을 확인했다. 모바일/데스크톱 전체 회차 및 공유를 포함한 tests/browser.smoke.mjs의 전체 실행 검증은 아직 완료하지 않았다. 별도 정적 TypeScript 검사는 아직 구성하지 않았다.

자매 사이트 비교와 앞으로 충족할 품질 기준은 [제품 기준](../product-plan.md)을 따른다.

## 부분 근거 결과 표시 (2026-10-04)

두 영역의 부분 근거에 따른 잠정 학년과 근거 부족의 하한 표시를 서로 다른 문구로 안내한다. 잠정 결과를 공유할 때도 “잠정 추정”을 포함한다.

## 짧은 어휘와 풀이 리듬 (2026-10-04)

생각할 시간이 필요한 문항의 지문 길이는 유지하며 문맥 어휘·문장 이해는 30초, 독해·글의 흐름은 40초로 조정한다. 새 짧은 어휘는 15초다. 초6~고3 각 4문항(28문항)을 추가해 총 364문항/91슬롯이다. 단어의 기본 뜻을 짧은 한국어 보기로 확인하고 문맥이 의미를 직접 설명하는 추론 문제와 구분한다. 학년은 앱 내부 난이도 기준이며 공식 단어별 학년 배정을 의미하지 않는다. 실제 학년별 정답률 검증은 아직 수행하지 않았다.

기본 문제은행에서는 첫 네 문제의 네 영역 균형을 유지하면서 어휘 차례에 짧은 어휘를 하나 출제하고, 6번째 문제에 두 번째 짧은 어휘를 출제한다. 이후 어휘가 선택되면 기존 문맥 어휘를 사용한다. 총 10문제와 여러 영역의 정답을 요구하는 학년 판정 기준은 유지한다. 짧은 어휘를 추가했다고 전체 어휘를 네 문제로 고정하지 않는다. 속도 가속은 기존 문제은행처럼 실측 보정 전 비활성화 상태를 유지한다.

### 재도전용 어휘 확장 (2026-10-04)

짧은 어휘를 학년별 4개에서 24개로 늘렸다(140개 추가, 총 168개). 기존 문맥 어휘 12개와 합쳐 학년별 어휘는 36개이며 전체 문제은행은 504개다. 회차당 짧은 어휘 2개 정책은 유지한다. 학년별 24개는 같은 학년에서 짧은 어휘만 보면 12회분의 규모이며, 학년 이동·영역별 후보·최근 기록 만료에 따라 반복 시점은 달라질 수 있다. 최근 400개 ID 회피 및 후보 소진 시 오래된 문항 우선 정책을 유지한다. 모든 단어는 서로 다른 짧은 어휘이며 정답과 오답은 같은 품사 또는 같은 의미 범주로 구성한다. 실제 학년 난이도는 플레이 데이터로 보정한다.
