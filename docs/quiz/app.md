# 7레벨 앱 연결

7레벨 × 12슬롯 × 2문항 = 168문항을 정적 앱에 연결했다. TypeScript 엔진을 그대로 사용하며 Node 24의 타입 제거 기능으로 빌드한다. UI는 DOM/CSS이며 빌드 시 합친 JSON을 가져온다.

시작/문제/해설/결과 화면, 20초 타이머, 넘기기, 다시 풀기, 문제별 내 답·정답 검토를 제공한다. 지문은 일반 문장 형태로 표시하고 해설 공간은 응답 후 생성한다. 보기 섞기는 pending의 정답 인덱스도 함께 변경한다.

첫 응답 후 상태를 동기적으로 잠가 중복 클릭을 방지한다. 타이머는 performance.now와 Date.now 경과 시간 중 큰 값을 사용해 백그라운드 복귀 시에도 만료를 확인한다. 해설 읽는 시간은 다음 문항에 포함하지 않는다. 최근 100개 ID만 로컬 저장하며 저장 실패 시에도 플레이는 가능하다.

공유는 Web Share → 클립보드 → 수동 복사 순서다. 개인 기록 동적 OG 이미지는 아직 없다.

Cloudflare: 빌드 명령 npm run build, 출력 디렉터리 dist, Node 24 이상. 모든 자산 경로는 상대적이다.

구조·엔진·빌드 테스트는 학년 난이도 정확성을 보장하지 않는다. 실제 학생/성인 플레이로 20초 읽기 부담, 보기 길이, 고1~고3 난이도 차이와 오답 매력도를 보정해야 한다. 공식 기본 어휘 목록 대조도 필요하다. expectedMs는 임시값이며 속도 가속은 아직 꺼져 있다.

현재 작업 환경에서 Chromium 다운로드가 실패하여 실제 모바일/데스크톱 렌더링 QA는 미완료다. tests/browser.smoke.mjs에 브라우저 검사 경로를 남겼다. 별도 정적 TypeScript 검사는 아직 구성하지 않았다.
