# What Grade English — Curriculum Design

- 작성일: 2026-10-03
- 대상 범위: 초등학교 6학년 ~ 고등학교 3학년
- 기준: 2022 개정 영어과 교육과정
- 목적: `what-grade-english`의 20초 적응형 퀴즈용 학년 수준 및 문제 설계 기준

> 이 문서는 국가 교육과정을 그대로 학년별 시험 범위로 옮긴 것이 아니다.
> 2022 개정 영어과 교육과정의 학년군/과목 구조를 기준점으로 삼아,
> 10문제·문제당 20초라는 게임 조건에 맞게 초6~고3의 7개 내부 Level로 세분화한 설계 문서다.

## 1. 공식 교육과정 기준

2022 개정 영어과 교육과정은 다음과 같이 구성된다.

- 초등학교: 3~4학년군, 5~6학년군
- 중학교: 1~3학년군
- 고등학교: 학년 단위가 아니라 과목 단위
  - 공통: 기본영어1·2, 공통영어1·2
  - 일반 선택: 영어Ⅰ, 영어Ⅱ, 영어 독해와 작문
  - 그 외 진로·융합 선택 과목

따라서 앱의 초6·중1·중2·중3 구분은 공식 성취기준을 그대로 나눈 것이 아니라,
학년군 내에서 어휘·문장 구조·추론 깊이·담화 복잡도를 점진적으로 높인 게임용 progression이다.

2022 개정 교육과정 적용 일정은 다음과 같다.

- 2025-03-01: 초1~4, 중1, 고1
- 2026-03-01: 초5~6, 중2, 고2
- 2027-03-01: 중3, 고3

앱은 장기 사용을 위해 전 범위를 2022 개정 교육과정 기준으로 통일한다.

## 2. 앱 Level 정의

| Level | 결과 표시 | 교육과정 기준점 | 앱 내부 어휘 기준 |
|---:|---|---|---:|
| 1 | 초등학교 6학년 | 초5~6 학년군 상단 | 누적 600 이내 |
| 2 | 중학교 1학년 | 중1~3 학년군 기초 | 약 900 |
| 3 | 중학교 2학년 | 중1~3 학년군 중간 | 약 1,200 |
| 4 | 중학교 3학년 | 중1~3 학년군 상단 | 1,500 이내 |
| 5 | 고등학교 1학년 | 공통영어1·2 | 1,800 이내 |
| 6 | 고등학교 2학년 | 영어Ⅰ 수준을 기준점으로 사용 | 2,000 이내 |
| 7 | 고등학교 3학년 | 영어Ⅱ 수준을 기준점으로 사용 | 2,500 이내 |

주의:

- 초5~6 누적 600, 중1~3 1,500, 공통영어1·2 1,800, 영어Ⅰ 2,000, 영어Ⅱ 2,500은 교육과정의 어휘 수 기준이다.
- 중1 약 900, 중2 약 1,200은 공식 학년별 수치가 아니라, 중학교 1~3학년군의 1,500단어 범위를 앱에서 세 단계로 탐색하기 위한 내부 휴리스틱이다.
- 고교학점제에서는 과목 이수 시점이 학교·학생에 따라 달라질 수 있으므로 고1=공통영어, 고2=영어Ⅰ, 고3=영어Ⅱ는 앱의 난이도 기준점이다.

## 3. 출제 Domain

영어판은 네 영역을 독립적으로 확인한다.

### vocabulary

문맥 속 단어·구의 의미와 자연스러운 쓰임을 본다.

- 단순 영한 뜻 암기보다 문장 안에서 의미를 판단하게 한다.
- 고학년에서는 다의어, 추상어, 유의어 간 미묘한 차이를 포함한다.

### usage

문법 지식, 문장 구조, 자연스러운 표현을 실제 문장에 적용하는 능력을 본다.

- 문법 용어 자체를 묻지 않는다.
- 시제, 태, 수식 관계, 절 구조, 연결 관계 등을 문장 안에서 판단하게 한다.

### reading

짧은 글의 세부 정보, 중심 내용, 목적, 주장, 추론, 함축 의미를 본다.

- 20초 게임이므로 긴 지문 대신 micro-passage를 사용한다.
- 상위 Level일수록 길이보다 추상성과 추론 깊이를 높인다.

### discourse

문장과 문장 사이의 논리 관계 및 글의 전개를 본다.

- 연결어
- 지시어
- 문장 순서
- 문장 삽입
- 원인·결과
- 대조·양보
- 예시·결론
- 전제·결론 관계

## 4. Level 1 — 초등학교 6학년

### 목표

짧고 익숙한 영어 문장과 일상생활 중심의 글을 이해할 수 있는지 확인한다.

### Vocabulary

- 학교, 가족, 음식, 날씨, 취미, 장소, 시간, 여행 등 일상 어휘
- 문맥을 이용한 기본 단어 의미
- 기초 동사와 형용사 구별

### Usage

- be동사 / 일반동사
- 현재 / 기본 과거 표현
- can 등 기본 조동사
- 기본 의문문
- 단수 / 복수
- 기본 전치사
- 간단한 비교 표현

### Reading

- 1~2문장
- 직접 제시된 정보 찾기
- 누가 / 언제 / 어디서 / 무엇을 했는지 파악
- 아주 짧은 글의 중심 내용

### Discourse

- and / but / because 수준의 기본 연결
- 간단한 사건 순서
- 대명사의 명확한 지시 대상

## 5. Level 2 — 중학교 1학년

### 목표

기본 문장 구조를 안정적으로 읽고, 간단한 두세 문장 사이의 관계를 이해하는지 확인한다.

### Vocabulary

- 학교생활, 감정, 취미, 일상 활동의 확장 어휘
- 짧은 문맥에서 적절한 단어 선택
- 기초 유의어 구별

### Usage

- 현재 / 과거 / 진행 표현의 구별
- 비교급·최상급 기초
- to부정사 기초
- 동명사 기초
- 기본 접속사
- 간단한 문장 결합

### Reading

- 2~3문장
- 구체적 정보
- 중심 내용
- 간단한 이유와 목적

### Discourse

- 대명사·지시 표현의 대상
- 원인 → 결과
- 시간 순서
- 기본 연결어 선택

## 6. Level 3 — 중학교 2학년

### 목표

문장 형태만이 아니라 의미와 문맥을 함께 고려하여 중학교 핵심 구조를 적용할 수 있는지 확인한다.

### Vocabulary

- 앱 내부 약 1,200단어 수준
- 문맥 어휘
- 다의어의 기본 의미 구별
- 문장 전체를 이용한 단어 추론

### Usage

- 완료 개념
- 수동 관계
- 관계 표현 기초
- to부정사 / 동명사 의미 차이
- 간접 질문
- 조금 더 복잡한 절 구조

### Reading

- 짧은 단락
- 중심 내용
- 이유·목적
- 직접 드러난 정보에서 한 단계 추론

### Discourse

- 앞뒤 문맥에 맞는 연결어
- 문장 간 원인·대조 관계
- 지시어의 대상
- 짧은 글의 순서

## 7. Level 4 — 중학교 3학년

### 목표

개별 문법 형태보다 문장 간 관계와 의미, 간단한 추론을 안정적으로 처리하는지 확인한다.

### Reading

## 11. 20초 문제 설계 규칙

앱의 목표는 어려운 문제를 오래 읽게 하는 것이 아니라, 짧은 시간 안에 실제 이해 수준을 구분하는 것이다.

### 공통 원칙

- 문제당 핵심 판단은 하나만 요구한다.
- 읽는 데 오래 걸려서 어려운 문제는 만들지 않는다.
- 긴 계산이나 긴 번역을 요구하지 않는다.
- 문법 용어 자체를 묻지 않는다.
- Vocabulary도 가능한 한 문맥 안에서 묻는다.
- 오답은 실제 학습자가 할 법한 오류를 반영한다.
- 상위 학년으로 갈수록 길이보다 추상성·함축·논리 관계를 높인다.

### 권장 텍스트 길이

| Level | 권장 문제/지문 길이 |
|---|---|
| 초6 | 약 5~15단어 |
| 중1 | 약 8~20단어 |
| 중2 | 약 10~25단어 |
| 중3 | 약 12~30단어 |
| 고1 | 약 15~35단어 |
| 고2 | 약 15~40단어 |
| 고3 | 약 15~40단어 |

이는 초기 게임 설계 기준이며 실제 플레이 데이터를 통해 조정한다.

## 12. 문제 메타데이터

```ts
type EnglishDomain =
  | 'vocabulary'
  | 'usage'
  | 'reading'
  | 'discourse';

type EnglishQuestion = {
  id: string;

  level: 1 | 2 | 3 | 4 | 5 | 6 | 7;
  schoolLevel: 'elementary' | 'middle' | 'high';
  grade: number;

  domain: EnglishDomain;
  skill: string;

  passage?: string;
  prompt: string;
  choices: string[];
  answer: number;
  explanation: string;

  expectedMs: number;
  fastThresholdMs?: number;
  speedEligible: boolean;
};
```

`domain`은 학년 판정 근거에 사용하고, `skill`은 동일 유형의 반복 출제를 막고 문제 다양성을 관리하는 데 사용한다.

예시 skill:

- `vocabulary.context-meaning`
- `vocabulary.synonym-in-context`
- `usage.tense`
- `usage.modifier`
- `usage.clause-relation`
- `reading.detail`
- `reading.main-idea`
- `reading.inference`
- `reading.implication`
- `discourse.connector`
- `discourse.reference`
- `discourse.order`
- `discourse.insertion`

## 13. 적응형 출제와 학년 판정 원칙

- 총 10문제
- 문제당 제한시간 20초
- 시작 Level은 중2(Level 3)
- 다음 문제의 탐색 Level과 최종 결과 Level은 분리한다.
- 빠른 정답은 다음 문제의 탐색 난이도를 올리는 데 사용할 수 있으나, 속도만으로 최종 학년을 올리지 않는다.
- 하나의 domain만 잘 푼 것으로 높은 학년을 확정하지 않는다.
- 해당 Level을 확정하려면 최소 3개의 정답 근거와 서로 다른 3개 domain의 근거를 요구하는 방향으로 설계한다.
- 상위 Level 정답은 하위 Level 이해의 보조 근거로 사용할 수 있지만, 상위 Level 실패만으로 하위 Level 정답 근거를 깎지 않는다.
- Reading 문제는 읽기 길이 차이가 크므로 초기 버전에서는 빠른 정답에 따른 +2 Level 가속 대상에서 제외하거나 별도 기준을 둔다.

최종 판정 수치는 실제 플레이 테스트 후 보정한다.

## 14. 문제 유형 확장 계획

초기에는 각 Level × 4 Domain마다 최소 3개의 대표 skill을 확보한다.

- 7 Level
- 4 Domain
- Domain당 최소 3 대표 유형
- 총 84개 이상의 출제 슬롯

이는 84개의 고정 문장을 의미하지 않는다.
검수된 문제 유형/템플릿을 먼저 정의한 뒤, 자연스러움과 정답 안정성이 보장되는 범위에서 제한적인 variation을 적용한다.

영어는 수학과 달리 무작위 단어 치환으로 부자연스러운 문장이 쉽게 만들어지므로,
런타임 완전 생성보다 다음 순서를 기본으로 한다.

1. 검수된 문항 또는 템플릿
2. 허용된 제한적 variation
3. 보기 순서 randomization
