# What Grade English 제품 기준

갱신: 2026-10-04

## 방향

수학 [what-grade](https://github.com/Jaeho211/what-grade)의 자매 사이트다. 디자인·구현 기술·진행 방식을 동일하게 맞출 필요는 없지만, 수학 사이트에서 해결한 사용성 문제와 품질 개선을 놓쳐 완성도가 퇴보해서는 안 된다. 영어에 맞는 차이는 목적과 검증 근거를 명시한다.

초6~고3의 영어 학년을 10문제·문제당 20~30초로 추정하는 재미용 퀴즈다. 결과는 한 학년으로 표시하되, 듣기·말하기·쓰기 전체 능력이나 실제 재학 학년을 진단한다고 표현하지 않는다.

## 제한시간 정책

문맥 어휘·문장 이해는 20초, 짧은 글 읽기·글의 흐름은 30초를 기본으로 한다. 지문·질문·네 보기 전체를 기준으로 검수하며, 긴 읽기 분량 자체로 난이도를 높이지 않는다. 예상 풀이 시간은 실측 전 임시값이다. 시간 초과의 판정 가중치는 별도 검증 과제로 남긴다. 확정 근거가 부족하면 두 영역·정답 두 개·정답률 75%의 부분 근거로 잠정 학년을 표시하며, 이 조건도 부족할 때만 초6 하한을 표시한다.

## 비교 기준과 현재 차이

수학의 최신 구현 및 docs/quiz/level-estimation.md를 기준으로 비교했다. 수학의 docs/product-plan.md는 초기 범위 기록이므로 현재 기능의 기준으로 사용하지 않는다.

| 항목 | 수학에서 확인한 경험 | 영어 현재 상태 | 영어 품질 기준·후속 조치 |
|---|---|---|---|
| 문제 다양성 | 미출제 개념 우선, 질문 구조가 다른 유형 추가 | ID 중복 금지, skill/family/영역 우선순위, 최근 400 ID | 숫자·단어만 바뀐 유사 문항과 같은 지문도 검사. 회차 내 다양성과 재도전 다양성을 별도 검증 |
| 학년 판정 | 탐색과 판정 분리, 여러 영역 근거, 초반 실수 회복 | 여러 영역 근거와 회복 검사 있음 | 한 유형만 잘 풀어 상위 학년이 되지 않게 유지. 상위 실패가 하위 근거를 지우지 않게 검사 |
| 근거 부족 결과 | 부분 근거와 낮게 출제된 수준으로 추정 | 확정 실패 시 두 영역 부분 근거로 잠정 판정 | 부분 근거 시나리오 검증 완료. 실제 사용자 응답으로 판정 보정 |
| 시간과 난이도 | 보정 전 임시 기준으로 빠른 정답 탐색 가속 | expectedMs 임시값, 실제 은행 가속 꺼짐 | 영어는 읽기 부담이 있으므로 실측 보정 후 도입. 느린 정답을 이해 부족으로 단정하지 않음 |
| 진행 | 짧은 피드백 후 자동 이동, 넘기기 즉시 이동 | 매 문항 해설과 다음 버튼, 넘기기도 해설 | 영어 학습에는 해설이 도움이 되나 10문항 흐름을 끊을 수 있음. 자동 진행과 결과에서 해설 확인하는 방식 비교 후 결정 |
| 가독성 | 수식·줄바꿈·굵기 개선 | 일반 영어 지문과 보기 표시 | 작은 모바일 화면에서 지문·질문·보기 전체의 읽기 부담, 줄바꿈, 타이머, 터치 영역 검증 |
| 해설 | 조건과 풀이 과정을 이해할 수 있게 개선 | 문항별 정답 해설 | 정답 근거를 지문의 표현과 연결하고, 헷갈리는 오답은 왜 틀렸는지 설명. 문항별 검수 필요 |
| 결과 요약 | 학년, 정답 수, 시간, 넘기기 등 | 학년, 정답 수, 정답 영역 수, 문항 검토 | 플레이 기록을 이해할 수 있게 요약 개선. 모든 수학 지표를 그대로 복제할 필요는 없음 |
| 결과 공유 | 개인 기록 URL 및 동적 OG 이미지, 받은 기록 표시 | 일반 홈 URL와 결과 문구 공유 | 개인 결과가 미리보기에 나타나고 받은 사람이 해당 기록에서 도전할 수 있게 구현 |
| 배포 | 앱 자산과 공유 기능 포함 | dist 정적 자산 배포 설정 추가, 첫 문항 흐름 확인 | 배포 성공 외에 JS/JSON 응답과 실제 화면·채점 흐름 확인 |

표의 후속 조치는 요구사항이며 구현 완료를 의미하지 않는다. 두 사이트 기능이 달라도 사용자 경험이 더 좋아진 근거가 있다면 허용한다.

## 다음 구현 순서

1. 근거 부족 판정 사례와 회차 내·재도전 유사 문항 사례를 검증하고 판정·출제 정책 개선.
2. 매 문항 해설/넘기기 흐름을 결정하고 모바일 전체 회차의 읽기 부담·가독성·해설 검수.
3. 개인 기록 공유 URL·미리보기·받은 기록 화면과 결과 요약 개선.
4. 실제 풀이 기록으로 문항 난이도와 예상 시간을 보정한 뒤 속도 가속 적용 여부 결정.

## 변경 완료 기준

- 전부 정답, 전부 미정답, 초반 실수 후 회복, 영역 편중, 중간 수준의 부분 정답, 넘기기·시간 초과 사례 검증.
- 동일 ID뿐 아니라 유사 family·지문 반복도 확인하며 후보 부족 시 정책을 설명.
- 모바일과 데스크톱에서 시작 → 10문항 → 결과 → 해설 → 공유 → 재도전 확인. 저장 차단 환경도 확인.
- 공유 개선 시 기록별 URL과 OG 결과, 잘못된 기록 입력, 공유 취소·복사 대안 확인.
- 문서에 구현 완료, 테스트 통과, 실제 플레이 보정을 구분해서 기록. 설계만 된 기능을 완료로 쓰지 않음.

## 문항 편집 검수 진행 (2026-10-04)

초6~고3 독해 84문항의 보기·해설과 일부 지문을 검수했다. 학년별 이해 부담 차이와 정답의 근거·추론 범위를 다듬었다. 전 학년 어휘·문장 이해·글의 흐름 252문항도 1차 편집 검수했고, 그중 75문항의 모호한 질문·보기, 반복 유형, 설명을 수정했다. 전체 336문항의 1차 편집 검수가 끝났으며 실제 난이도 보정과는 구분한다. 상세 기록은 [문항 검수](quiz/content-review.md)에 있으며, 실제 풀이 시간·난이도 실측은 아직 수행하지 않았다.
